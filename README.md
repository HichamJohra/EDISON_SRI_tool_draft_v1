# EDISON SRI upgrade decision tool – draft v1

Multi-page Dash app drafting the EDISON tool: from an SRI assessment, recommend which
smart-ready services to upgrade, to which level and at what cost (target mode or budget mode).

**Everything is dummy:** 8-service catalogue, cost matrices and a placeholder SRI formula.

## Run (uv)

Dependencies are managed with [uv](https://docs.astral.sh/uv/): `pyproject.toml` lists them, `uv.lock` pins
the exact versions (commit it), `.python-version` sets Python 3.13.

```bash
uv sync                       # first time: creates .venv and uv.lock, installs app + dev dependencies
uv run python app.py          # http://127.0.0.1:8050
uv run pytest                 # core logic tests
```

Common commands:

```bash
uv add <package>              # add a dependency (updates pyproject.toml and uv.lock)
uv add --dev <package>        # add a development-only dependency
uv remove <package>
uv lock --upgrade             # upgrade all pinned versions within the constraints, then `uv sync`
```

PyCharm: Settings → Project → Python Interpreter → Add Interpreter → Add Local Interpreter → uv
(or select the existing `.venv\Scripts\python.exe` created by `uv sync`).

## Structure

```
app.py                  Dash app, navbar with logos, shared dcc.Store state, page container
pages/                  One file per page (auto-registered with dash.register_page)
  home.py               Overview and links to the steps
  assessment.py         1. Building data + current service levels (editable table)
  objectives.py         2. Target class or budget
  results.py            3. Recommended package, KPIs, cost–SRI curve
  about.py              What is dummy and what comes next
components/ui.py        Card, control, KPI, graph and table helpers (as in the NSBI app)
edison_sri/             Core logic, no Dash imports (testable on its own)
  catalogue.py          Dummy services, domain weights, cost matrices, defaults
  scoring.py            Placeholder SRI score and Annex VIII classes
  optimiser.py          Cost of upgrades, cost–SRI front, target/budget selection
assets/style.css        Styling copied from the NSBI app (loaded automatically by Dash)
assets/logos/           EDISON and SINTEF logos; assets/favicon.ico = SINTEF icon
tests/test_core.py      Tests for the core logic
pyproject.toml          Dependencies (uv), pytest settings
uv.lock                 Exact pinned versions (generated by uv)
.python-version         Python version used by uv
```
